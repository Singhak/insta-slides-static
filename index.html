Create slides with AI (optional)
  1. Write your question above and choose the number of slides.
  2. Tap Copy prompt, then open a chatbot such as ChatGPT, Gemini, or Claude and paste/send the prompt. Share to app… is an optional shortcut on supported devices.
  3. Copy the chatbot’s complete reply, return here, and either tap Paste & load or paste it into the box below.
  4. If you pasted the reply into the box, tap Load reply. Your generated slides will appear for editing.
No API key is needed. Nothing is sent automatically: you choose which chatbot to use and manually send it the copied prompt.
If loading fails, ask the chatbot: “Return only the JSON, with no introduction or code fences.”

Help & things to know
Quick start
  1. Edit slides directly, or expand Create slides with AI to generate a draft (AI is optional).
  2. Paste formatted slide text or use B/I/U and list buttons for bold, italic, underline and lists. Style it on the right; the preview updates live.
  3. Use Save project to download a portable project file (including uploaded backgrounds); Open project restores it in this browser.
  4. Click Generate & download zip → PNG slides + caption.txt. A local readability/content check runs first.
  5. Upload the PNGs to Instagram as a carousel and paste the caption.
Choosing an AI source
  • Local model: free and private. Needs Ollama or LM Studio running on your computer.
  • Own API key: Claude or any OpenAI-compatible service. You pay your provider per use.
  • Copy prompt → paste reply: no key or setup. You manually send the copied prompt to a chatbot and paste its reply back here.
Local model setup (Ollama / LM Studio)
  • Windows — Ollama: fully quit Ollama from its notification-area/tray icon first. Open PowerShell and run $env:OLLAMA_ORIGINS="*"; ollama serve. Leave that window open; this allows browser requests to Ollama.
  • Open a second PowerShell window and run ollama run qwen2.5:1.5b. Ollama downloads the model if needed; you can replace the model name with another chat model. Keep Ollama running while you use the app.
  • In this app, set the base URL to http://localhost:11434/v1, click Detect, choose the model, enter a question, then click AI Generate.
  • macOS / Linux: quit Ollama, then start it from a terminal with OLLAMA_ORIGINS="*" ollama serve. In another terminal run ollama run qwen2.5:1.5b, then use the same base URL and Detect steps above.
  • * allows browser pages to connect to your local Ollama server. Use this only on a trusted computer; do not expose Ollama to an untrusted network.
  • LM Studio: base URL http://localhost:1234/v1. Start the server and turn on Enable CORS.
  • Expand Create slides with AI to automatically look for installed models. Click Detect to refresh the list.
  • Small models sometimes return broken JSON. Retry, use a bigger model, or use copy-paste mode.
Privacy & API keys
  • Everything runs in your browser; there is no server of ours. Your questions go only to the AI source you choose.
  • Project files and export checks are handled locally in this browser; no project data is uploaded.
  • Your key is saved in this browser only (localStorage) and sent only to the base URL shown. Don’t enter a key on a shared or public computer; clear it when done.
  • Browser-side keys can be read by anyone with access to this browser, so use a key with a spending limit.
Tips for good slides
  • Keep each slide to one idea: title under 8 words, body under 30 words.
  • Slide 1 is the hook; the last slide should ask people to save, share or follow.
  • Use Portrait 1080×1350 for the most feed space. Long text shrinks automatically to fit.
  • On photo backgrounds, raise Image darkness so the text stays readable.
  • Hindi or other scripts: pick a matching font, e.g. Noto Sans Devanagari.
  • Add Instagram, X, or YouTube handles in Style → Social branding to place your account names on every slide.
Troubleshooting
  • Model detection failed: make sure Ollama is running, use http://localhost:11434/v1, and allow this page in Ollama’s CORS origins. After changing OLLAMA_ORIGINS, restart Ollama and click Detect again.
  • Font looks different / not loading: fonts come from Google Fonts and need internet. Check the font name spelling.
  • Install the app: on Android/Chrome, open Insta Slides over HTTPS and tap Install app (or use the browser menu). On iPhone/iPad, use Share → Add to Home Screen.
  • Export shows an error: a background image from another website can be blocked; upload the image file instead.
  • Nothing happens on AI Generate: check that a model is chosen and your question isn’t empty.
  • Images are saved to your browser’s downloads folder as instagram_post.zip.
